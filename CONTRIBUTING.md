# Contributing

Thanks for helping improve this list.

## How to add a resource

Please add resources in the relevant section using this format:

```md
| [Resource Name](https://example.com/) | One-line factual description. | Free / Freemium / Paid | MIT / GPL-3.0 / CC BY-SA 4.0 / License not specified |
```

## Guidelines

- Prefer official websites, repositories, documentation pages, or AnkiWeb pages.
- Include license information when it is clearly stated.
- Use `License not specified` when no clear license is available.
- Use `Proprietary` for commercial products, paid books, or closed-source apps.
- Keep descriptions short, factual, and neutral.
- Do not add pirated decks, unauthorized book scans, copyrighted media mirrors, or unofficial downloads of paid content.
- For dictionaries, decks, or datasets built from third-party sources, mention upstream license terms where possible.

## Suggested categories

- Open data, APIs, dictionaries, and developer libraries
- Stroke order, handwriting, decomposition, radicals, and frequency
- Apps, study tools, and practice sites
- Etymology, radicals, and character history
- Anki decks, add-ons, and deck generators
- Meta lists and broader Japanese-learning collections

## Pull request checklist

Before submitting:

- [ ] The link works.
- [ ] The description is one sentence.
- [ ] Access type is marked as Free, Freemium, Paid, or Free to access.
- [ ] License / terms are included when available.
- [ ] The resource is relevant to Japanese kanji.
